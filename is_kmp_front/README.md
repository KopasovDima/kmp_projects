# Фронтенд-сервис личного кабинета ИС КМП

## Технологии и фреймворки
* TypeScript
* React - https://react.dev/
* Ant Design - https://ant.design/

## Для работы с проектом требуется установить
* NodeJS (используемая версия - v22.14.0)
* npm (используемая версия - 10.9.2) - обычно устанавливается совместно с NodeJS

## Как запустить локально
1. Установка зависимостей
    ```shell
   npm i
    ```
2. Настройка переменных окружения для локального запуска
   ```shell
   cp -n .env.example .env.local
   ```

   Настройка переменных окружения для прод сборки
   ```shell
   cp -n .env.example .env.production
   ```

   В этих файлах указываются значения
   ```shell
   VITE_IS_PRODUCTION - true или false # является ли сборка прод версией (используется для использования https в ссылках и добавления предупреждения сверху)
   VITE_AUTH_SERVER_URL # полный url адрес сервера авторизации
   VITE_SERVER_URL # полный url адрес основного сервера
   VITE_WS_SERVER_URL # полный url адрес основного сервера для работы с веб-сокетами
   ```
3. Запуск проекта
    ```shell
   npm run dev
   ```

## Добавление ip-адреса сервера в файл hosts
Если деплой проводится ручным копированием файлов, то этот пункт необязателен. Также он не нужен для DMZ сервера (из-за закрытого ssh порта)
<br><br>
В целях безопасности вместо прямого указания ip-адреса сервера для деплоя используется имя is_kmp_server.
Для правильной работы деплоя в файле
 - ***/etc/hosts (Linux)***
 - ***C:/Windows/System32/drivers/etc/hosts (Windows)***

нужно указать правильный ip-адрес сервера:
```shell
  [ip.address] is_kmp_server
```

и добавить в ~/.ssh/config ssh-ключ для подключения к серверу с именем is_kmp_server:
```shell
  HOST is_kmp_server
      USER [user_name]
      IdentityFile [file_path]
```


## Как залить обновление на DEV-сервер по SSH
1. Создать сборку проекта (предварительно нужно установить зависимости и настроить переменные окружения)
   ```shell
   npm run build
   ```
   В директории `dist` будут записаны все необходимые файлы
   <br><br>

2. Запустить деплой (автоматически копируются файлы на сервер по ssh)
   ```shell
   npm run deploy
   ```

## Как залить обновление на PROD-сервер через REDVIRT
1. Подключиться в браузере к DMZ-серверу через интерфейс RED-виртуализации
2. Перейти в директорию проекта `is_kmp_front`
   ```shell
   cd /var/apps/is_kmp/is_kmp_front/
   ```
3. Подтянуть изменения через Git
   ```shell
   git pull origin master
   ```
   Или внести изменения напрямую на сервере <br><br>
4. Создать сборку проекта
    ```shell
    npm run build
    ```
